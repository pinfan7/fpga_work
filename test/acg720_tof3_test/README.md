# ACG720 三路 GY-53L1 测距测试工程

适用 ACG720 60K / GW5AT-LV60PG484AC1/I0，50 MHz。
独立测试左前、正前、右前三个 GY-53L1（VL53L1X + 板载 MCU），UART 模式。
这不是自动避障行驶固件：电机的 PWMA/AIN1/AIN2/PWMB/BIN1/BIN2/STBY 与舵机脉冲全部固定为低。
测试前断开电机和舵机动力，信号线可保留；编码器信号端在本工程中未用。
原有电机、舵机和摄像头工程未修改。

## 接线

编号是开发板 P7 排针的物理编号，不是 GPIO 用户编号。方向 L/F/R 按车头朝前时定义。

| 模块 | 模块 TX (Pin3) 接 FPGA输入 | 模块 RX (Pin4) 接 FPGA输出 |
|---|---|---|
| 左前 L | P7.25 / B17 / tof_l_rx | P7.26 / B18 / tof_l_tx |
| 正前 F | P7.27 / C18 / tof_f_rx | P7.28 / C19 / tof_f_tx |
| 右前 R | P7.31 / D20 / tof_r_rx | P7.32 / C20 / tof_r_tx |

每个模块 Pin1 接稳定3.3V、Pin2 接公共地；地可通过分配端子接 P7.30。
P7.29 为板载3.3V，仅在确认电源余量后取电；外部电源与板载电源不要并联。
模块 PS/Pin6 保持默认高电平 UART 模式，不接地、不擅自外接5V。
模块 Pin5、7、8、9、10 不外接；另一组 Pin11/12 不另接一套电源。
手册仅标TTL，接线前核实TX幅度和RX门限与3.3V FPGA兼容，不能因供电支持5V就认定信号支持5V。
三个模块TX不能并联。P7与J1 TFT共用信号，不连接J1 TFT；HDMI另用接口。
电机和舵机动力供电不可作为模块供电。按板上1脚标记和奇偶编号定位，断电接线。

### 原有引脚保留

| 功能 | P7物理脚 / FPGA封装管脚 |
|---|---|
| 舵机 | 9 / E13 |
| PWMA、AIN1、AIN2 | 13/C13、14/B13、15/D14 |
| PWMB、BIN2、BIN1、STBY | 16/D15、17/C14、18/C15、19/B15 |
| 左编码器A/B | 20/B16、21/D17 |
| 右编码器A/B | 22/C17、23/E16 |

## 下载

1. 打开本目录 tof3_test.gprj，顶层 tof3_test_top。
2. 直接测试预编译文件时，无需先运行编译；Programmer选择 GW5AT-60B / SRAM Program。
3. 下载 prebuilt/TOF3_TEST_SRAM.fs，不操作Flash。SRAM配置断电丢失。
4. 松开S1～S4，传感器保持上电。S0复位FPGA，并重新发送初始化命令。
5. 等待约2秒，观察LED。此固件不会输出转向PWM或使能电机。

## 上电配置和收包

模块串口要求9600bps、8N1。复位后等待1秒，再向三个模块分别输出相同配置：
- A5 51 F6：短距离模式，手册量程约1.3m；本项目优先近距测试，不以4m为验收目标。
- A5 64 09：测量时间55ms。
- A5 45 EA：连续输出。

前两条命令完成后各等待150ms；不发送掉电保存，不反复写模块配置存储器。
配置只发送一次，不包含配置应答确认，命令是否生效需观察串口状态字；正常预期状态字为01。
若模块曾保存115200波特率，默认9600程序无法通信：使用原厂上位机将模块恢复9600，或修改TOF_BAUD后重新编译。

解析固定8字节测距包：5A 5A 15 03 DH DL MODE SUM；SUM为前7字节累加的低8位。
距离单位mm，MODE高4位为RangeStatus。校验通过且状态为0、距离50～4000mm才置valid。
50～4000mm是软件保守筛选，不能扩大短距模式的实际量程。
坏校验、串口帧错误、传感器无效状态或距离越界会记录历史错误，但不覆盖最后一次有效距离，也不刷新该有效距离的计时；连续500ms没有新的有效测距结果才撤销valid。首次收到有效数据前valid保持0。
帧内字节间隔超过50ms丢弃残帧；支持重新寻找帧头。接收到坏数据后可自动恢复有效状态。
fault_seen是复位清除的历史故障标记，不会因为后续收到正常包而清除。

## LED和按键：不用电脑也可测试

默认松开S1/S2/S3时：

| LED | 含义 |
|---|---|
| D0、D1、D2 | 左前、正前、右前数据有效 |
| D3、D4、D5 | 左前、正前、右前有效距离小于300mm |
| D6 | 任一路当前无效/超时，或曾出现坏包、无效状态等历史故障 |
| D7 | 约1Hz心跳 |

按住S1：8个LED显示左前距离的厘米整数；S2为正前，S3为右前。
此时D0是最低位、D7是最高位，二进制显示，不再显示上述状态。
例如250mm -> 25cm -> D0、D3、D4亮。无效显示全灭，超过255cm饱和显示255。
多键同时按下时S1优先，其次S2，再S3。S4预留，无测试功能；S0清历史故障并重新配置。
因状态无效而D6亮不一定是硬件坏，例如启动未收到包、无目标或目标超量程。
距离显示模式下全灭不能代表0cm，应松开按键看通道有效灯。

## 可选：USB转TTL查看具体距离

额外预留 debug_tx=P7.33/E19，115200bps、8N1，每250ms输出一行。
- P7.33 -> USB转TTL适配器 RX。
- FPGA GND -> 适配器 GND。
- 适配器TX和电源脚不接；适配器必须支持3.3V逻辑，不能使用RS232电平。
- 这是外接适配器接线，不是板载USB串口。

任意串口助手可读取，例如：
L=00FA/S=01/1 F=03E8/S=01/1 R=00C8/S=01/1

距离和S字段均为十六进制，末尾1/0为valid。00FA=250mm，03E8=1000mm，00C8=200mm。
超时后仍保留上次距离和状态字，但valid=0，不可把旧距离当实时有效距离。
可选运行 `python -m pip install pyserial`，再 `python tools/monitor.py COM5`，显示十进制毫米值。

## 建议验收

1. 先接一个模块，距白色纸箱约20～100cm，确认对应有效灯和数值；其余无数据通道会导致D6亮。
2. 三个模块全部接好，用纸箱分别靠近各探头；确认L/F/R与实际安装位置一致。
3. 目标位于300mm以内时对应近距灯亮，移到更远处熄灭；阈值无迟滞，边界抖动属于预期。
4. 用串口观察有效状态；让目标超出量程，确认不会把无效读数当可靠距离。
5. 断电后移除某路TX线，再上电测试，确认该路有效灯撤销；不要在电机带动力时做此测试。
6. 正常通信后短按S0，再确认三路恢复；若仍有有效状态且D6亮，检查是否历史错误，串口查各路状态。

## 修改与重编译

工程可放在任意目录，构建脚本以自身目录为基准定位文件。
用Gowin gw_sh.exe执行build.tcl，或在IDE设置顶层并启用SSPI作为普通IO后Run All。
新生成文件为impl/pnr/tof3_test.fs；prebuilt是交付快照，不会随之后编译自动更新。
参数位于rtl/tof3_test_top.v：NEAR_MM、TIMEOUT_MS、TOF_BAUD等。
HDMI显示、自动避障行驶和电机闭环不包含在这个独立传感器测试中。

## 仿真

安装Icarus Verilog后执行 sim/run_tests.ps1，可用-IcarusBin指定bin目录。
测试并发收包、帧头恢复、坏校验、无效状态、越界、帧错误恢复、残帧超时、数据超时、LED、初始化串口字节和调试串口，以及电机/舵机输出恒低。
团队已确认三个模块通过实车接线测试；离线仿真与实物验证分别记录，不据此补填测距精度或光学互扰指标。当前源码与历史预编译快照不能仅凭文件名认定一致，修改源码后应重新构建。
