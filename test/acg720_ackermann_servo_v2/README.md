# 阿克曼舵机独立测试

目标板ACG720 60K，舵机LD-1501MG。按键和PWM由FPGA实现，不包含摄像头、IMU显示或直流电机驱动。

## 当前源码的按键功能

松开所有按键后，S1启用并请求中位；再次按S1停用PWM。S0复位并抑制输出。

| 按键 | 命令 | 当前源码默认脉宽 |
|---|---|---|
| S2 | 固定左预设，标称相对中位−10° | 1389μs |
| S3 | 回中 | 1500μs |
| S4 | 固定右预设，标称相对中位+10° | 1611μs |

重复按键不累计角度。10°由厂家500—2500μs对应180°的线性关系推算，不是实测前轮转角；1500μs也不代表机械上已经回正。默认短脉宽为左，安装方向相反时修改LEFT_SMALLER_PULSE并重新编译。

## 接线

本独立工程的舵机信号为 **E13 / P7第9脚**。V6运动工程使用 **F13**，两者不可混用接线说明。

舵机使用独立、能够提供足够电流的6—8.4V电源，电源地与FPGA地共地。舵机功率电流不经过FPGA GPIO，TB6612不参与舵机控制。测试前断开直流电机动力，确认机械限位及电源后再启用。

## 编译与固件

工程为ackermann_servo_v2.gprj，顶层acg720_servo_top。使用高云执行本目录build.tcl完成构建，再下载新生成的impl/pnr/ackermann_servo_v2.fs。

prebuilt中的02_SERVO_V2_ANGLE_SRAM.fs是历史交付快照，和当前源码构建产物不一致；不能把本表10°参数自动套用到旧固件。本次只更新仿真与说明，没有替换这份历史固件。

构建目录不随本次源代码提交，保留的历史编译报告见reports/build_evidence。

## 指示灯

D0启用；D1松键许可；D2中位命令；D3左预设；D4右预设；D5达到软件限位；D6固定灭；D7心跳。当前±10°预设恰好到1389/1611μs软件限位，因此S2或S4后D5亮正常。LED不提供舵机实际角度反馈。
