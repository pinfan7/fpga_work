# V25 黄色目标视觉 + IMU 自主接近

本工程实现黄色目标识别、IMU 航向辅助接近与停车。参赛团队已于 2026-11-02 确认该工程完成实车测试：黄色目标识别、自动转向接近及停车成功。软件验证与静态时序结果见 `reports/验证结果.md`；实车功能通过不表示整工程静态时序已收敛。

## 实现功能

1. 摄像头实时识别符合原 V21 颜色、形状和连续帧条件的黄色物体，显示目标框，继续在 HDMI 显示 IMU 数据。
2. 目标框中心相对画面中心的偏差转换为目标方位角。利用该帧对应的近似历史 IMU 航向，生成绝对期望航向。
3. IMU 持续反馈当前航向，用航向误差和转动速度控制舵机。接近目标方向时减小转向，转过头时反向纠偏；不会强行保持启动时的原航向。
4. 编码器和原有 PI 闭环控制电机速度。目标偏离中心、航向误差较大或距离较近时减速。
5. 正前 TOF 距离不大于 **100mm** 时停车。目标框同时位于画面中心 ±24 像素时记为“到达”；未对准时记为保护停车。保持原 V21 阈值，没有改成 40cm。
6. 目标丢失、相机数据陈旧、正前测距无效、侧面过近、IMU 异常/数据停止更新、编码器异常、超时或超程会停车，需要人工重新启动。

这是一版目标接近程序，不包含 V24 的选侧绕障、返回原线或两米终点逻辑。遇到其他障碍物时可保护停车，不会规划绕行。

## 工程与烧录

- 打开 `visual_nav_imu_v25.gprj`，顶层 `ackermann_auto_top`。
- 运行 `build.cmd` 可重新综合、布局布线；日志在 `reports/gowin_build.log`。
- 本次固件位置、编译和时序结果见 `reports/验证结果.md`。
- `open_gao.cmd` 打开本版 GAO 配置和本版固件；版本探针 `dbg_version=0x2501`。
- 文件夹可直接使用，不需要解压。

## 接线和操作

- 舵机信号 **F13**，20ms 周期，中位 **1400μs**，左端限值 **1039μs**，右端限值 **1850μs**。这些是 PWM 脉宽限值，实际车轮角度由机械安装决定。其他物理引脚沿用 V21。
- IMU 使用原有 I²C 接口 A18/A19，继续由显示子系统唯一控制，没有另建竞争总线控制器。
- 上电保持小车静止，等待 IMU 完成 256 个静止样本的校准，再等待有效目标、相机、正前 TOF 就绪。
- **S1**：释放后重新按下，启动本次目标接近。先预备约 1 秒，再前进。上电一直按住不会启动。
- **S3**：停止；**S0**：复位。S3/S0 对电机输出有直接关断路径。
- **S2**：切换显示源，导航需要实际摄像头图像；**S4**：原有 IMU 会话启停/重新初始化按键。行驶时改变 IMU 会话会导致保护停车。
- **D5** 亮表示可以按 S1；**D6** 表示相机、目标、正前 TOF 或 IMU 尚未就绪；D0 行驶、D1 故障、D2 近距离减速、D3 预备、D4 到达、D7 心跳。
- 到达或异常停车时会短刹约 300ms，随后电机待机。停车后不会因为传感器恢复自动出发，需再次按 S1。
- 舵机在接受启动后才输出脉冲，停止/故障后完成当前 PWM 帧再关闭脉冲。没有舵机位置反馈，停止后不保证主动回中。

## 必须了解的测量条件

黄色目标需要先进入视野，满足原 V21 的尺寸、长宽比和填充率条件；本版没有原地搜索目标。沿用了原先较适合竖直紧凑目标的检测器，不是对任意黄色区域都生成导航目标。

正前 TOF 必须能照射到摄像头识别的同一物体。本版没有视觉测距或视觉/TOF 目标关联；TOF 看见其他物体也会停车。贴在地面的黄色胶带不能保证被水平安装的 TOF 测到，不能将本版直接视为胶带末端精确停车方案。

IMU 航向来自陀螺仪积分，适用于近水平地面上的短时接近，会漂移。`YAW_SIGN=1` 沿用 V24 左转为正的约定，实际安装需要确认方向。

图像方向按默认 **0.0625°/像素** 线性近似换算；画面边缘约 ±20°。它不是镜头标定结果。历史航向补偿默认 **100ms**，用于近似抵消摄像头、DDR、显示和检测流水线延迟；不是逐帧精确时间戳同步。镜头、刷新率和实际延迟不同，需要实测调节这两个参数。

## 参数修改位置

下列位置只是说明，本次没有放宽原来的黄色/停车阈值。

| 想调整什么 | 文件 | 参数/位置 |
|---|---|---|
| 舵机中位、左右脉宽限值 | `rtl/drive/ackermann_auto_top.v` | `SERVO_CENTER_US=1400`、`SERVO_LEFT_US=1039`、`SERVO_RIGHT_US=1850` |
| 靠近后停车距离 | 同上 | `NAV_STOP_MM=100`，单位 mm；运行时必须仍满足下述启动距离条件 |
| 启动最小距离、侧面保护距离 | `rtl/nav/visual_approach_controller.v` | `START_MM=150`、`SIDE_STOP_MM=150`；增大停车距离时应同步保证 `START_MM > STOP_MM` |
| 黄色颜色范围 | `rtl/yellow_cup_detector.v` | `R_MIN`、`G_MIN`、`RB_MIN`、`GB_MIN`、`RG_MAX`、`GR_MAX`；“放宽颜色识别”需分别调整各条件，不能统一全部增大 |
| 黄色物体最小面积、尺寸 | 同上 | `MIN_TILES`、`MIN_W`、`MIN_H` 及形状/填充率筛选 |
| 画面中心容差 | `rtl/nav/visual_approach_controller.v` | `centered` 的 ±24 像素；16 像素转向死区在 `visual_imu_heading.v` 的 `bearing` 表达式 |
| 正常、接近、爬行速度 | `rtl/nav/visual_approach_controller.v` | `FAR_RPM=30`、`NEAR_RPM=15`、`CREEP_RPM=10`；减速距离 500/250mm 在 `desired_rpm` |
| IMU 正负方向 | `rtl/drive/ackermann_auto_top.v` | `YAW_SIGN=1`；左转时 IMU yaw 应增加，若安装相反用 -1 |
| 图像左右镜像 | 同上 | `CAMERA_MIRROR=0`；目标在画面左侧应向左转 |
| 像素到方向角的换算 | 同上 | `BEARING_Q8_PER_PIXEL=16`，单位 1/256°/像素 |
| 航向纠偏、转动阻尼 | 同上 | `HEADING_KP=8` μs/°、`RATE_KD=1` μs/(°/s) |
| 视觉延迟补偿 | 同上 | `VISION_LATENCY_MS=100`，取 0～320ms 内的 10ms 整数倍；0 表示使用当前航向 |
| IMU 数据超时 | `rtl/nav/visual_approach_controller.v` | `IMU_STALE_MS=100`；这是新增保护，原 V21 其他阈值保持不变 |

`TURN_PULSE_US` 和顶部一组旧 `TOF_SLOW_MM/TOF_STOP_MM` 等参数是兼容保留项，不控制本版视觉接近的转向幅度或终点；请使用表中实际接入控制器的参数。

## GAO 与故障码

新探针按 32 位有符号数解释：`dbg_heading_q8`、`dbg_goal_q8`、`dbg_heading_error_q8` 除以 256 得到当前/期望/误差角度；左为正。`dbg_rate_q8/256` 是 °/s。

`dbg_imu_flags[3:0]` 依次为航向控制就绪、IMU 新鲜有效、底层 IMU 有效、IMU 更新脉冲。GAO 是 50Hz 快照，不能要求每次都捕获单周期更新脉冲。

| `dbg_code` | 原因 |
|---|---|
| 1 | 目标丢失、跳变或相机/目标更新过期 |
| 2 | 正前 TOF 未配置/数据无效 |
| 3 | 电机命令存在但持续没有编码器位移 |
| 4 | 编码器持续显示反方向 |
| 5 | 编码器反馈停止更新 |
| 6 | 单次行驶超过 45 秒 |
| 7 | 任一有效侧面 TOF 距离 ≤150mm |
| 8 | 正前 TOF ≤100mm，但还未在 TRACK 阶段对准目标 |
| 9 | 任一轮累计行驶估计 ≥3 米 |
| 10 | IMU 无效、更新超过 100ms，或航向控制未就绪 |

状态 `dbg_phase`：0 待机，1 预备，2 接近，10 到达，11 故障，12 手动停止。
