连接说明与按键

开发板网口连接电脑的千兆网口。电脑有线 IPv4：192.168.0.3，掩码：255.255.255.0，网关和 DNS 留空。FPGA 固定发送到 UDP 6102 端口。显示屏可不连接。

网页同步 HDMI 输出：上电默认显示彩条，按 S2 切换至摄像头，S3 切换文字叠加，S1 按原工程逻辑控制 IMU。画面由 FPGA 生成，电脑仅接收和显示，不执行视觉识别或电机控制。

连接后仍无画面：检查网卡协商速度是否为 1.0 Gbps，接收程序是否仍在运行，以及 Windows 是否允许 Python 的 UDP 接收。此发送端未实现 ARP / ICMP，ping 不通不能据此判定图像链路失败。
